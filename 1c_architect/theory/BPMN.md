# Основы синтаксиса BPMN 2.0

BPMN (Business Process Model and Notation) — стандарт графического описания бизнес-процессов. Вот ключевые элементы синтаксиса:

## 1. Основные элементы (Flow Objects)

### **События (Events)**
- **Круг** - что-то, что происходит в процессе
- **Типы:**
  - Начальное: ⚪ (пустой)
  - Промежуточное: ⚪ с двойной границей
  - Конечное: ⚪ с жирной границей
  - Символ внутри круга определяет тип события

### **Действия (Activities)**
- **Прямоугольник со скругленными углами**
- **Виды:**
  - Задача (Task): базовое действие
  - Подпроцесс (Sub-process): ⬜ с знаком + внизу
  - Транзакция: ⬜ с двойной границей

### **Шлюзы (Gateways)**
- **Ромб** - точки принятия решений
- **Типы:**
  - Эксклюзивный (XOR): ✗ внутри ромба
  - Параллельный (AND): ＋ внутри ромба
  - Инклюзивный (OR): ○ внутри ромба
  - Сложный (Complex): ✶ внутри ромба
  - Событийный: ромб с символом события

## 2. Соединяющие элементы (Connecting Objects)

### **Потоки управления (Sequence Flows)**
- **Сплошная линия со стрелкой** →
- Показывают порядок выполнения

### **Потоки сообщений (Message Flows)**
- **Пунктирная линия со стрелкой и кругом на конце** ---○→
- Связь между участниками/пулами

### **Ассоциации (Associations)**
- **Пунктирная линия без стрелки или со стрелкой** ---
- Связывают артефакты с элементами потока

## 3. Артефакты (Artifacts)

### **Данные (Data)**
- **Лист бумаги с загнутым уголком**
- **Типы:**
  - Объект данных: лист
  - Ввод данных: лист со стрелкой вниз
  - Вывод данных: лист со стрелкой вверх
  - Хранилище данных: лист с полосой внизу

### **Группа (Group)**
- **Прямоугольник из пунктирных линий** вокруг элементов
- Для логического группирования

### **Аннотация (Text Annotation)**
- **Открытая скобка с текстом** ┌───┐
- Для комментариев и пояснений

## 4. Дорожки (Swimlanes)

### **Пул (Pool)**
- **Большой прямоугольник** - представляет участника
- Основной контейнер для процесса

### **Дорожка (Lane)**
- **Разделение внутри пула** - роли/подразделения

## 6. Правила хорошего тона

1. **Поток слева направо или сверху вниз**
2. **Один начальный и один конечный** событие на процесс
3. **Минимальное пересечение** линий
4. **Единый уровень детализации** в одной диаграмме
5. **Использование подпроцессов** для сложных действий
6. **Четкие названия** для всех элементов
7. **Логичное размещение** элементов по дорожкам

## 7. Расширенные элементы

### **Типы событий:**
- **Сообщение**: конверт ✉
- **Таймер**: часы ⏰  
- **Ошибка**: крестик ✗
- **Эскалация**: флажок 🚩
- **Условное**: буква C
- **Ссылка**: стрелки по кругу 🔄

### **Типы задач:**
- **Пользовательская**: человечек
- **Сервисная**: шестеренка ⚙
- **Ручная**: рука 👋
- **Бизнес-правило**: линейка с буквой R
- **Сценарий**: кино-клип 🎬
- **Абстрактная**: пустая

## 8. Практические советы

```bpmn
// Плохо:
Слишком много элементов на одной диаграмме
Пересекающиеся потоки
Отсутствие описаний

// Хорошо:
1 процесс = 1 диаграмма
Использование подпроцессов
Четкие названия и описания
Логичные переходы
```

BPMN позволяет описывать процессы с разной степенью детализации — от высокоуровневых до исполняемых моделей, которые можно автоматизировать в BPMS-системах.
