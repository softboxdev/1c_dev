
# Практическая работа: Настройка обмена через RabbitMQ в 1С

## 📋 Что мы сделаем:
Настроим простой обмен сообщениями между двумя 1С-базами через RabbitMQ.
- **База А** будет отправлять сообщения
- **База Б** будет получать сообщения

---

## 🚀 Часть 1: Установка RabbitMQ

### 1. Установите RabbitMQ (Windows)
1. Скачайте установщик: https://rabbitmq.com/install-windows.html
2. Установите Erlang (требуется для RabbitMQ)
3. Запустите RabbitMQ

### 2. Включите веб-интерфейс
Откройте командную строку (от имени администратора):
```cmd
cd "C:\Program Files\RabbitMQ Server\rabbitmq_server-3.13.1\sbin"
rabbitmq-plugins enable rabbitmq_management
```

### 3. Проверьте установку
Откройте в браузере: `http://localhost:15672`
- Логин: `guest`
- Пароль: `guest`

## 🛠️ Часть 2: Подготовка 1С (общая часть)

### 1. Создайте общий модуль "ОбменСообщениями"
```bsl
// Общий модуль. Клиент и Сервер

#Область ПрограммныйИнтерфейс

// Отправка сообщения
Процедура ОтправитьСообщение(ТекстСообщения, ИмяОчереди = "1С_Сообщения") Экспорт
    
    // 1. Подготовка URL RabbitMQ
    URL = "http://localhost:15672/api/exchanges/%2F/amq.default/publish";
    
    // 2. Создаем тело запроса
    Тело = Новый Структура;
    
    // 3. Настраиваем свойства
    Свойства = Новый Структура;
    Свойства.Вставить("content_type", "text/plain");
    
    // 4. Формируем полное тело
    Тело.Вставить("properties", Свойства);
    Тело.Вставить("routing_key", ИмяОчереди); // Имя очереди = ключ маршрутизации
    Тело.Вставить("payload", ТекстСообщения);
    Тело.Вставить("payload_encoding", "string");
    
    // 5. Создаем HTTP-запрос
    Запрос = Новый HTTPЗапрос(URL);
    Запрос.УстановитьИмяМетода(HTTPМетод.POST);
    
    // 6. Устанавливаем заголовки
    Запрос.Заголовки.Вставить("Content-Type", "application/json");
    
    // 7. Аутентификация (логин/пароль по умолчанию)
    ЛогинПароль = "guest:guest";
    Запрос.Заголовки.Вставить("Authorization", "Basic " + Base64Строка(ЛогинПароль));
    
    // 8. Конвертируем структуру в JSON
    ЗаписьJSON = Новый ЗаписьJSON;
    ЗаписьJSON.Записать(Тело);
    JSONТекст = ЗаписьJSON.Закрыть();
    
    Запрос.УстановитьТелоИзСтроки(JSONТекст);
    
    // 9. Отправляем запрос
    Попытка
        HTTPСоединение = Новый HTTPСоединение("localhost", 15672);
        Ответ = HTTPСоединение.ОтправитьДляОбработки(Запрос);
        
        Если Ответ.КодСостояния = 200 Тогда
            Сообщить("Сообщение отправлено успешно!");
        Иначе
            Сообщить("Ошибка отправки: " + Ответ.ПолучитьТелоКакСтроку());
        КонецЕсли;
        
    Исключение
        Сообщить("Ошибка соединения: " + ОписаниеОшибки());
    КонецПопытки;
    
КонецПроцедуры

#КонецОбласти
```

### 2. Создайте обработку "ОтправитьСообщение"
```bsl
// Обработка. ОтправитьСообщение

Перем КнОтправить;

&НаКлиенте
Процедура Открыть(Команда)
    ОткрытьФорму();
КонецПроцедуры

&НаКлиенте
Процедура ОтправитьСообщение(Команда)
    
    // Получаем текст из поля формы
    Текст = Объект.ТекстСообщения;
    
    Если ПустаяСтрока(Текст) Тогда
        Сообщить("Введите текст сообщения!");
        Возврат;
    КонецЕсли;
    
    // Отправляем сообщение через общий модуль
    ОбменСообщениями.ОтправитьСообщение(Текст);
    
    // Очищаем поле после отправки
    Объект.ТекстСообщения = "";
    
КонецПроцедуры
```

## 📥 Часть 3: Создаем получателя (подписчика)

### 1. Создайте обработку "ПолучательСообщений"
```bsl
// Обработка. ПолучательСообщений

Перем ТаймерПолучения;

&НаКлиенте
Процедура ПриОткрытии(Отказ)
    
    // Создаем таймер для периодической проверки сообщений
    ТаймерПолучения = Новый Таймер;
    ТаймерПолучения.Период = 5000; // Проверяем каждые 5 секунд
    ТаймерПолучения.ПодпискаНаСобытие = Истина;
    
    // Подписываемся на событие таймера
    ТаймерПолучения.ПриСрабатывании = "ПолучитьСообщения";
    
    // Запускаем таймер
    ТаймерПолучения.Запустить();
    
КонецПроцедуры

&НаКлиенте
Процедура ПолучитьСообщения(Таймер = Неопределено)
    
    // URL для получения сообщений из очереди
    URL = "http://localhost:15672/api/queues/%2F/1С_Сообщения/get";
    
    // Создаем тело запроса для получения
    Тело = Новый Структура;
    Тело.Вставить("count", 10); // Максимум 10 сообщений за раз
    Тело.Вставить("requeue", Ложь); // Удаляем из очереди после получения
    Тело.Вставить("encoding", "auto");
    
    // Создаем HTTP-запрос
    Запрос = Новый HTTPЗапрос(URL);
    Запрос.УстановитьИмяМетода(HTTPМетод.POST);
    Запрос.Заголовки.Вставить("Content-Type", "application/json");
    Запрос.Заголовки.Вставить("Authorization", "Basic " + Base64Строка("guest:guest"));
    
    // Конвертируем в JSON
    ЗаписьJSON = Новый ЗаписьJSON;
    ЗаписьJSON.Записать(Тело);
    Запрос.УстановитьТелоИзСтроки(ЗаписьJSON.Закрыть());
    
    Попытка
        HTTPСоединение = Новый HTTPСоединение("localhost", 15672);
        Ответ = HTTPСоединение.ОтправитьДляОбработки(Запрос);
        
        Если Ответ.КодСостояния = 200 Тогда
            // Получаем ответ как JSON
            ТекстОтвета = Ответ.ПолучитьТелоКакСтроку();
            
            Если Не ПустаяСтрока(ТекстОтвета) Тогда
                // Парсим JSON
                ЧтениеJSON = Новый ЧтениеJSON;
                ЧтениеJSON.УстановитьСтроку(ТекстОтвета);
                Сообщения = ПрочитатьJSON(ЧтениеJSON);
                ЧтениеJSON.Закрыть();
                
                // Выводим сообщения
                Для Каждого Сообщение Из Сообщения Цикл
                    Если ТипЗнч(Сообщение) = Тип("Структура") Тогда
                        Текст = Сообщение.payload;
                        Объект.ЖурналСообщений.Добавить();
                        Объект.ЖурналСообщений.ДатаВремя = ТекущаяДата();
                        Объект.ЖурналСообщений.Текст = Текст;
                    КонецЕсли;
                КонецЦикла;
                
                Объект.ЖурналСообщений.АктивнаяСтрока = Объект.ЖурналСообщений.Количество() - 1;
            КонецЕсли;
        КонецЕсли;
        
    Исключение
        // Ошибка соединения - просто игнорируем, попробуем в следующий раз
    КонецПопытки;
    
КонецПроцедуры

&НаКлиенте
Процедура ПриЗакрытии()
    
    // Останавливаем таймер при закрытии формы
    Если ТаймерПолучения <> Неопределено Тогда
        ТаймерПолучения.Остановить();
    КонецЕсли;
    
КонецПроцедуры

// Вспомогательная функция для чтения JSON
Функция ПрочитатьJSON(ЧтениеJSON)
    
    Пока ЧтениеJSON.Прочитать() Цикл
        
        Если ЧтениеJSON.ТекущийТипДанных = ТипДанныхJSON.НачалоОбъекта Тогда
            Результат = Новый Соответствие;
            Пока ЧтениеJSON.Прочитать() И ЧтениеJSON.ТекущийТипДанных <> ТипДанныхJSON.КонецОбъекта Цикл
                Ключ = ЧтениеJSON.ТекущееЗначение;
                ЧтениеJSON.Прочитать();
                Результат[Ключ] = ПрочитатьJSON(ЧтениеJSON);
            КонецЦикла;
            
        ИначеЕсли ЧтениеJSON.ТекущийТипДанных = ТипДанныхJSON.НачалоМассива Тогда
            Результат = Новый Массив;
            Пока ЧтениеJSON.Прочитать() И ЧтениеJSON.ТекущийТипДанных <> ТипДанныхJSON.КонецМассива Цикл
                Результат.Добавить(ПрочитатьJSON(ЧтениеJSON));
            КонецЦикла;
            
        Иначе
            Результат = ЧтениеJSON.ТекущееЗначение;
        КонецЕсли;
        
        Возврат Результат;
    КонецЦикла;
    
    Возврат Неопределено;
    
КонецФункции
```

## 🎯 Часть 4: Настройка RabbitMQ через веб-интерфейс

### 1. Создайте очередь для 1С
1. Откройте `http://localhost:15672`
2. Перейдите в раздел **Queues**
3. Нажмите **Add a new queue**
4. Введите имя: `1С_Сообщения`
5. Нажмите **Add queue**

### 2. Настройте права доступа
1. Перейдите в раздел **Admin**
2. Убедитесь, что пользователь `guest` имеет доступ
   - Нажмите на пользователя `guest`
   - Убедитесь, что у него есть права на виртуальный хост `/`

## 🔧 Часть 6: Устранение проблем

### Если не работает отправка:
1. **Проверьте RabbitMQ**: `http://localhost:15672` открывается?
2. **Проверьте порт**: RabbitMQ слушает на порту 15672
3. **Проверьте аутентификацию**: логин/пароль `guest:guest`
4. **Проверьте брандмауэр**: разрешите порт 15672

### Если не работает получение:
1. **Проверьте имя очереди**: должно быть `1С_Сообщения`
2. **Проверьте таймер**: обработка "ПолучательСообщений" запущена?
3. **Проверьте очередь в RabbitMQ**: есть ли сообщения?

## ⚠️ ШАГ 8: Решение типичных проблем новичков

### Проблема: "Неизвестный тип HTTPЗапрос"
**Решение:**
1. Убедитесь, что версия платформы 8.3.6+
2. Проверьте настройки модуля:
   ```
   ✅ Сервер: ДА
   ✅ Клиент: ДА
   ```

### Проблема: "Нет доступа к интернету из 1С"
**Решение:**
1. Проверьте настройки proxy:
   - Служебное меню → Настройки
   - Интернет-соединение → Настройка прокси
2. Добавьте исключение для localhost

### Проблема: "Ошибка авторизации RabbitMQ"
**Решение:**
1. Проверьте логин/пароль в коде: `guest:guest`
2. Убедитесь, что RabbitMQ запущен
3. Проверьте порт: 15672

### Проблема: "Не видно обработок в меню"
**Решение:**
1. Зайдите в режим "Все функции"
2. Или настройте команды интерфейса:
   - Администрирование → Настройка команд интерфейса
   - Добавьте обработки в нужный раздел
