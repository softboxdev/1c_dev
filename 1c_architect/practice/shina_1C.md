Ниже — **упрощённый пошаговый пример** настройки синхронизации данных между двумя информационными базами «1С:Предприятие» через «1С:Шину» (на примере обмена между «Управление торговлей» и «Бухгалтерия предприятия КОРП»).

## 1. Подготовка инфраструктуры

- Установите сервер «1С:Шина» и запустите его.
- Убедитесь, что обе информационные базы (ИБ) работают на поддерживаемой версии платформы «1С:Предприятие» (8.3.15+).
- Настройте сетевое взаимодействие: сервер «1С:Шины» должен быть доступен из обеих ИБ.

## 2. Создание проекта в «1С:Шине»

1. В веб‑интерфейсе «1С:Шины» зайдите в раздел **«Приложения»** → **«+ Новое приложение»**.
2. Выберите **«Новый проект»**, укажите:
   - имя проекта (например, `Exchange_UT_BP`);
   - версию;
   - имя приложения (например, `exchange_app`);
   - тип СУБД (обычно `SQLite` для тестов);
   - включите **«Режим разработки»**.
3. Нажмите **«Создать»**. Проект появится со статусом **«Создано»**, затем — **«Выполняется»**.


## 3. Настройка схемы интеграции

1. Откройте проект в среде разработки (кнопка **«Редактировать»**).
2. В подсистеме **«Основной»** щёлкните правой кнопкой мыши → **«Новый»** → **«Элемент проекта»** → выберите **«Процесс интеграции»**. Задайте имя (например, `MainExchange`).
3. Добавьте элементы:
   - **GroupParticipants**: `SourceUT` (для «Управление торговлей») и `DestinationBP` (для «Бухгалтерия»).
   - **Channel1CSource** (источник) и **Channel1CDestination** (приёмник). Свяжите их маршрутом.
4. Настройте **HTTP‑сервис** для приёма запросов:
   - В проекте добавьте элемент **«HTTP‑сервис»** (имя, например, `HttpExchange`).
   - Для сервиса создайте **шаблон URL** (например, `/api/exchange/send`).
5. Сохраните и опубликуйте проект (клавиша **F9**). Статус должен стать **«Запущен»**.

## 4. Регистрация информационных систем в «1С:Шине»

1. В интерфейсе «1С:Шины» перейдите на вкладку **«Инфосистемы»** → **«+ Добавить систему»**.
2. Для каждой ИБ укажите:
   - **Код** (уникальный идентификатор, например, `UT` и `BP`);
   - **Название** (например, «Управление торговлей» и «Бухгалтерия»).
3. Для каждой системы нажмите **«Выдать API‑ключ»**. Сохраните:
   - **Идентификатор ключа**;
   - **Секрет клиента**.

## 5. Настройка информационной базы «Управление торговлей» (источник)

1. В конфигураторе «Управление торговлей»:
   - Создайте **расширение** для модификаций.
   - Добавьте **интеграционный сервис** (например, `ExchangeService`).
2. Настройте подключение к «1С:Шине»:
   - Укажите **URL** опубликованного приложения (например, `http://сервер-шины:9090/applications/exchange_app`).
   - Введите **Идентификатор ключа** и **Секрет клиента** для системы `UT`.
3. Загрузите **каналы интеграции** из «1С:Шины»:
   - В настройках сервиса выберите **«Получить каналы сервиса»** → укажите канал, связанный с `SourceUT`.
4. Реализуйте **обработчик отправки** (например, в модуле `ExchangeService`):
   ```bsl
   Процедура ОтправитьДанные()
       Сообщение = Новый СообщениеИнтеграции();
       Сообщение.Данные = ... // ваши данные (например, документы)
       ОбменДляСтарыхВерсий.ОтправитьСообщениеВУзлы(Сообщение, "SourceUT");
   КонецПроцедуры
   ```
5. Сохраните расширение и обновите конфигурацию.

## 6. Настройка информационной базы «Бухгалтерия предприятия» (приёмник)

1. В конфигураторе «Бухгалтерия»:
   - Создайте **расширение** (если ещё нет).
   - Добавьте **интеграционный сервис** (например, `ReceiveService`).
2. Настройте подключение к «1С:Шине» (аналогично шагу 5.2):
   - URL приложения;
   - Идентификатор и секрет для системы `BP`.
3. Загрузите **каналы интеграции** (канал для `DestinationBP`).
4. Реализуйте **обработчик приёма**:
   ```bsl
   Процедура ОбработатьВходящееСообщение(Сообщение)
       // Здесь логика обработки данных (например, создание документов)
       ЗаписьЖурналаРегистрации("Получено сообщение", УровеньЖурнала.Информация, Сообщение.Данные);
   КонецПроцедуры
   ```
5. Подключите обработчик к сервису интеграции (в свойствах сервиса укажите процедуру).
6. Сохраните и обновите конфигурацию.



### 1. Подготовка среды разработки

1. Запустите **конфигуратор «1С:Предприятие»** под учётной записью с правами администратора.
2. Откройте конфигурацию **«Управление торговлей»** (УТ).
3. Убедитесь, что версия платформы — **не ниже 8.3.15** (требуется для работы с «1С:Шиной»).

### 2. Создание расширения для модификаций

1. В меню **«Конфигурация»** → **«Расширения конфигурации»** нажмите **«Добавить»**.
2. Задайте имя расширения (например, `Интеграция_с_1СШиной`).
3. Установите флажки:
   - **«Безопасный режим»** — *снять* (требуется для низкоуровневых операций);
   - **«Защита от опасных действий»** — *снять*.
4. Сохраните расширение (**F2**).

### 3. Добавление интеграционного сервиса

1. В дереве конфигурации расширения перейдите в раздел **«Общие»** → **«Сервисы интеграции»**.
2. Нажмите **«Добавить»**, укажите имя сервиса (например, `СервисИнтеграцииУТ`).
3. Заполните свойства:
   - **Имя сервиса** — `СервисИнтеграцииУТ`;
   - **Пространство имён** — `http://example.com/integration/ut` (уникальный URI);
   - **Версия** — `1.0`.
4. Сохраните объект.

### 4. Настройка подключения к «1С:Шине»

1. В модуле сервиса (`СервисИнтеграцииУТ`) добавьте процедуру инициализации:

```bsl
Процедура ИнициализироватьПодключение()
    ПараметрыПодключения = Новый Структура;
    ПараметрыПодключения.Вставить("URL", "http://сервер-шины:9090/applications/exchange_app");
    ПараметрыПодключения.Вставить("ClientID", "UT"); // Код системы из «1С:Шины»
    ПараметрыПодключения.Вставить("ClientSecret", "ваш_секретный_ключ");
    
    // Инициализация клиента интеграции
    КлиентИнтеграции = Интеграция.СоздатьКлиент(ПараметрыПодключения);
КонецПроцедуры
```

2. Вызовите процедуру при старте сервиса (в обработчике `ПриНачалеРаботыСистемы`):

```bsl
Процедура ПриНачалеРаботыСистемы()
    СервисИнтеграцииУТ.ИнициализироватьПодключение();
КонецПроцедуры
```

### 5. Загрузка каналов интеграции

1. В конфигураторе перейдите в **«Администрирование»** → **«Сервис»** → **«Настройки внешнего сервиса интеграции»**.
2. Нажмите **«Получить каналы сервиса»**.
3. В диалоговом окне укажите:
   - **URL приложения** — адрес «1С:Шины»;
   - **ClientID** и **ClientSecret** — данные из шага 4.2;
   - **Канал** — выберите `SourceUT` (созданный в «1С:Шине»).
4. Нажмите **«Загрузить»**. В системе появится новый канал.

### 6. Реализация обработчика отправки данных

1. В модуле сервиса создайте процедуру отправки:

```bsl
Процедура ОтправитьДокумент(ДокументСсылка)
    // 1. Формирование сообщения
    Сообщение = Новый СообщениеИнтеграции();
    Сообщение.Заголовок.Установить("ТипДанных", "Документ.РеализацияТоваров");
    Сообщение.Заголовок.Установить("Идентификатор", ДокументСсылка.УникальныйИдентификатор());
    
    // 2. Заполнение тела сообщения
    Тело = Новый Соответствие;
    Тело["Номер"] = ДокументСсылка.Номер;
    Тело["Дата"] = ДокументСсылка.Дата;
    Тело["Сумма"] = ДокументСсылка.СуммаДокумента;
    
    Сообщение.Данные = Новый ХранилищеЗначения(Тело);
    
    // 3. Отправка через канал
    Канал = КаналыИнтеграции.НайтиПоКоду("SourceUT");
    Если Не Канал.Пустая() Тогда
        Канал.Отправить(Сообщение);
        ЗаписьЖурналаРегистрации("Отправка документа", УровеньЖурнала.Информация, ДокументСсылка);
    Иначе
        ЗаписьЖурналаРегистрации("Канал не найден", УровеньЖурнала.Ошибка);
    КонецЕсли;
КонецПроцедуры
```

2. Добавьте вызов процедуры в нужный интерфейс (например, кнопку в форме документа):

```bsl
&НаКлиенте
Процедура КнопкаОтправитьНаСервере()
    ОтправитьДокумент(Объект.Ссылка);
КонецПроцедуры
```

### 7. Настройка прав доступа

1. Перейдите в **«Администрирование»** → **«Пользователи и права»** → **«Профили доступа»**.
2. Создайте профиль (например, `Интегратор УТ`) с правами:
   - **«Использование сервисов интеграции»**;
   - **«Администрирование сервисов интеграции»** (если требуется).
3. Назначьте профиль нужным пользователям.

### 8. Публикация сервиса в режиме «1С:Предприятие»

1. Сохраните конфигурацию (**F7**).
2. Запустите базу в режиме **«1С:Предприятие»**.
3. Перейдите в **«Администрирование»** → **«Сервис»** → **«Настройки внешнего сервиса интеграции»**.
4. Заполните поля:
   - **URL сервиса** — `http://сервер-шины:9090/applications/exchange_app`;
   - **Клиентский идентификатор** — `UT`;
   - **Секрет клиента** — ваш API‑ключ;
   - **Сервис интеграции** — `СервисИнтеграцииУТ`.
5. Активируйте сервис (флажок **«Использовать»**).



## 7. Настройка обмена в режиме «1С:Предприятие»

1. В обеих ИБ перейдите в раздел **«Администрирование»** → **«Сервис»** → **«Настройки внешнего сервиса интеграции»**.
2. Укажите:
   - **URL** приложения «1С:Шины»;
   - **Логин** и **пароль** (используйте API‑ключ и секрет);
   - **Имя сервиса** (например, `ExchangeService` и `ReceiveService`).
3. Включите **активность сервиса** (флажок **«Использовать»**).

## 8. Тестирование обмена

1. В «Управление торговлей» запустите процедуру отправки данных (например, через форму или регламентное задание).
2. В «Бухгалтерии» проверьте:
   - поступление сообщения (журнал регистрации);
   - создание объектов (документов, справочников) по логике обработчика.
3. При ошибках:
   - проверьте **логи «1С:Шины»** (в веб‑интерфейсе);
   - убедитесь, что **каналы** активны;
   - сверьте **API‑ключи** и URL.

## Итог

После выполнения этих шагов данные из «Управление торговлей» будут передаваться в «Бухгалтерию» через «1С:Шину». Для обратного обмена повторите шаги 5–8, поменяв роли ИБ.
