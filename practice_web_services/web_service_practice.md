Пошаговое руководство по созданию http-сервиса.
Цель. Научиться создавать http сервисы на платформе 1С: Предприятие 8.

План обучения:

Подготовка объектов метаданных для сервиса.

Создадим чистую базу данных.
Добавим в базу данных справочник «Номенклатура»
Добавим реквизиты в справочник «Номенклатура»
Добавим регистр сведений «Штрих коды»
Добавим измерения и ресурсы в регистр сведений «Штрих коды»
Добавить общий модуль «Общего назначения»
В общем модуле создадим функцию, которая вернет JSON строку с нашими данными
Запустим платформу 1С: Предприятие 8 в режиме «предприятие» и заполним данными справочник «Номенклатура» и регистр сведений «Штрих коды»
Создание http сервиса:

Открываем дерево метаданных ветка «Общие» - «HTTP-сервисы». Позиционируемся на объекте «HTTP-сервисы»
Добавляем новый сервис.
Закладка «Основные» поле «Имя». Задаем имя. Имя может быть любым. Желательно чтобы имя сервиса отражало его суть.
Закладка «Основные» поле «Корневой URL». Необходимо задать имя корневого url.
Закладка «Шаблоны URL». Добавляем новый шаблон. Задаем ему имя. Имя может быть любым. Желательно, чтобы имя отражало предназначение шаблона.
В шаблоне добавляем метод. В данном методе будем программный код шаблона.
 

Публикация http сервиса:

ВАЖНО, НА ВАШЕМ КОМПЬЮТЕРЕ УЖЕ ДОЛЖЕН БЫТЬ УСТАНОВЛЕН ВЕБ СЕРВЕР (APACHE (2.2 ИЛИ 2.4) ИЛИ ISS)
Запускаем конфигуратор 1С: Предприятия 8 в режиме «Запуск от имени администратора»
Главное меню Администрирование – Публикация на веб-сервере
Закладка «Основные» поле имя. Необходимо задать имя. Имя должно быть сформировано по правилу формирования имен переменных. Имя не должно содержать русских букв.
Закладка «Основные» поле «Каталог». Создаем на жестком диске каталог (например www) и указываем к нему путь. В данный каталог будет размещена публикация.
Закладка «Основные» - закладка «HTTP сервисы». Устанавливаем флаг около нашего сервиса.
Нажимаем кнопку «Опубликовать». Перезапускаем веб сервер.
Проверка работы http сервиса:

Запускаем браузер.
Прописываем в строке браузера ip адрес компьютера на котором работает веб сервис (в нашем случае это наша локальная машина)
После этого если веб сервер запущен, мы должны увидеть в браузере соответствующее сообщение.
Если все нормально, в строке браузера прописываем путь к нашему сервису по определенному правилу и получаем результат работы сервиса.

Это руководство предполагает, что у вас уже установлена платформа 1С:Предприятие 8.3 (например, версии 8.3.20 или выше) и веб-сервер (Apache 2.4).

### **Часть 1: Подготовка базы данных и объектов метаданных**

#### **Шаг 1.1: Создание новой пустой базы данных**
1. Запустите **1С:Предприятие**.
2. Выберите **"Создать новую информационную базу"**.
3. Выберите **"Создание информационной базы без конфигурации"**.
4. Укажите имя базы (например, `УчебныйHTTPService`), выберите каталог для ее размещения и нажмите **"Готово"**.

#### **Шаг 1.2: Добавление справочника "Номенклатура"**
1. В открывшемся окне **Конфигуратора** нажмите правой кнопкой мыши на ветку **"Справочники"** в дереве конфигурации.
2. Выберите **"Добавить"**.
3. В открывшемся окне:
    * **Имя:** `Номенклатура`
    * **Синоним:** `Номенклатура`
    * Нажмите **"OK"**.

#### **Шаг 1.3: Добавление реквизитов в справочник "Номенклатура"**
1. Откройте созданный справочник `Номенклатура` (дважды кликните на нем).
2. Перейдите на вкладку **"Реквизиты"**.
3. Добавьте реквизиты с помощью кнопки "+":
    * **Имя:** `Артикул`, **Тип:** `Строка`, **Длина:** 25.
    * **Имя:** `Описание`, **Тип:** `Строка`, **Длина:** 200.
    * **Имя:** `Цена`, **Тип:** `Число`, **Длина:** 15, **Точность:** 2.
4. Перейдите на вкладку **"Формы"**, нажмите **"Добавить"** для элемента справочника и примите форму по умолчанию (платформа создаст ее автоматически).

#### **Шаг 1.4: Добавление регистра сведений "Штрихкоды"**
1. Правой кнопкой на ветке **"Регистры сведений"** -> **"Добавить"**.
2. **Имя:** `Штрихкоды`, **Синоним:** `Штрихкоды`.
3. **Периодичность:** `Непериодический` (галочку снимите).

#### **Шаг 1.5: Добавление измерений и ресурсов в регистр "Штрихкоды"**
1. Откройте регистр `Штрихкоды`.
2. На вкладке **"Измерения"**:
    * Добавьте измерение **Имя:** `Номенклатура`, **Тип:** `СправочникСсылка.Номенклатура`.
    * Добавьте измерение **Имя:** `ВидКода`, **Тип:** `ПеречислениеСсылка.ВидыШтрихКодов` (пока пропустите, сначала нужно создать перечисление).
3. Вернитесь в дерево конфигурации.
4. Создайте **Перечисление** с именем `ВидыШтрихКодов`. Добавьте в него предопределенные значения: `EAN13`, `Code128`.
5. Вернитесь в регистр `Штрихкоды`. Для измерения `ВидКода` выберите созданное перечисление.
6. На вкладке **"Ресурсы"**:
    * Добавьте ресурс **Имя:** `Код`, **Тип:** `Строка`, **Длина:** 50.
7. На вкладке **"Формы"** добавьте форму списка (примите по умолчанию).

#### **Шаг 1.6: Добавление общего модуля "ОбщегоНазначения"**
1. Правой кнопкой на ветке **"Общие модули"** -> **"Добавить"**.
2. **Имя:** `ОбщегоНазначения`.
3. Установите **флаги (свойства модуля)**:
    * ✅ **Глобальный** (важно!)
    * ✅ **Сервер** (важно!)
    * ❌ Клиент, ❌ Внешнее соединение, ❌ Клиент (управляемое приложение) — не нужны.
4. Откройте модуль и напишите в нем **серверную** функцию.

```bsl
// ОбщегоНазначения
Функция ПолучитьДанныеНоменклатурыВJSON() Экспорт

    Результат = Новый Структура;
    РезультатВМассиве = Новый Массив;

    // Выберем все элементы справочника Номенклатура
    Выборка = Справочники.Номенклатура.Выбрать();
    Пока Выборка.Следующий() Цикл

        Элемент = Новый Структура;
        Элемент.Вставить("Наименование", Выборка.Наименование);
        Элемент.Вставить("Артикул", Выборка.Артикул);
        Элемент.Вставить("Цена", Выборка.Цена);
        Элемент.Вставить("Описание", Выборка.Описание);

        // Найдем штрихкоды для этого элемента
        ШтрихКодыМассив = Новый Массив;
        Запрос = Новый Запрос;
        Запрос.Текст = "
        |ВЫБРАТЬ
        |   Штрихкоды.Код
        |ИЗ
        |   РегистрСведений.Штрихкоды КАК Штрихкоды
        |ГДЕ
        |   Штрихкоды.Номенклатура = &Номенклатура
        |";

        Запрос.УстановитьПараметр("Номенклатура", Выборка.Ссылка);
        РезультатЗапроса = Запрос.Выполнить();
        ВыборкаШтрихкодов = РезультатЗапроса.Выбрать();
        Пока ВыборкаШтрихкодов.Следующий() Цикл
            ШтрихКодыМассив.Добавить(ВыборкаШтрихкодов.Код);
        КонецЦикла;

        Элемент.Вставить("ШтрихКоды", ШтрихКодыМассив);
        РезультатВМассиве.Добавить(Элемент);

    КонецЦикла;

    Результат.Вставить("Номенклатура", РезультатВМассиве);
    Результат.Вставить("КоличествоЗаписей", РезультатВМассиве.Количество());
    Результат.Вставить("ДатаФормирования", ТекущаяДата());

    // Преобразуем в JSON
    ЗаписьJSON = Новый ЗаписьJSON;
    ЗаписьJSON.УстановитьСтроку();
    ПисатьJSON(ЗаписьJSON, Результат);

    Возврат ЗаписьJSON.Закрыть();

КонецФункции
```

#### **Шаг 1.7: Заполнение тестовыми данными**
1. **Сохраните конфигурацию (F7)**.
2. Запустите базу в режиме **"Предприятие"** (обычно `F5` или `Ctrl+F5` из Конфигуратора).
3. В открывшемся 1С:Предприятии:
    * Откройте справочник **"Номенклатура"**. Создайте 3-5 записей, заполнив наименование, артикул, цену, описание.
    * Откройте регистр **"Штрихкоды"**. Для каждой номенклатуры добавьте 1-2 штрихкода (просто введите любые числа для теста).

### **Часть 2: Создание HTTP-сервиса**

#### **Шаг 2.1-2.5: Создание HTTP-сервиса и шаблона URL**
1. Вернитесь в **Конфигуратор**.
2. В дереве конфигурации найдите ветку **"Общие"** -> **"HTTP-сервисы"**.
3. **Правой кнопкой -> Добавить**.
4. **Закладка "Основные":**
    * **Имя:** `УчебныйСервис`
    * **Корневой URL:** `/УчебныйСервис/v1` (важно! Слеш в начале обязателен).
5. Перейдите на **закладку "Шаблоны URL"**.
6. Нажмите **"Добавить"**.
    * **Имя шаблона:** `КаталогНоменклатуры`
    * **URL:** `catalog/` (относительно корневого URL. Полный путь будет: `/УчебныйСервис/v1/catalog/`)
7. В таблице **"Методы"** для этого шаблона нажмите **"Добавить"**.
    * **Имя метода:** `ПолучитьКаталог`
    * **Тип:** `GET` (оставьте по умолчанию).
8. **ВНИМАНИЕ:** Чтобы добавить код, нужно **дважды кликнуть** на имени метода `ПолучитьКаталог` в этой таблице. Откроется окно модуля обработчика.
9. **Вставьте в модуль следующий код:**

```bsl
&НаСервере
Процедура ПолучитьКаталог(Запрос, Ответ, ПараметрыЗапроса) Экспорт

    // Устанавливаем правильный заголовок для JSON
    Ответ.УстановитьЗаголовок("Content-Type", "application/json; charset=utf-8");

    Попытка
        // Вызываем нашу подготовленную функцию из общего модуля
        ДанныеJSON = ОбщегоНазначения.ПолучитьДанныеНоменклатурыВJSON();
        Ответ.УстановитьТелоИзСтроки(ДанныеJSON, КодировкаТекста.UTF8);

    Исключение
        // В случае ошибки возвращаем JSON с описанием ошибки
        СообщениеОбОшибке = Новый Структура;
        СообщениеОбОшибке.Вставить("error", ОписаниеОшибки());
        ЗаписьJSON = Новый ЗаписьJSON;
        ЗаписьJSON.УстановитьСтроку();
        ПисатьJSON(ЗаписьJSON, СообщениеОбОшибке);
        Ответ.КодСостояния = 500;
        Ответ.УстановитьТелоИзСтроки(ЗаписьJSON.Закрыть(), КодировкаТекста.UTF8);
    КонецПопытки;

КонецПроцедуры
```

10. **Сохраните конфигурацию (F7).**

### **Часть 3: Публикация HTTP-сервиса**

#### **Шаг 3.1: Подготовка к публикации (Windows + Apache 2.4)**
1. Убедитесь, что у вас установлен **Apache 2.4** и он запущен.
2. **Запустите Конфигуратор 1С от имени Администратора** (это важно для записи в каталог веб-сервера).

#### **Шаг 3.2: Публикация**
1. В меню Конфигуратора выберите **"Администрирование" -> "Публикация на веб-сервере..."**.
2. **Закладка "Основные":**
    * **Имя публикации:** `My1CService` (только латиница, без пробелов).
    * **Каталог публикации:** Укажите существующий каталог, который "видит" Apache (например, `C:\Apache24\htdocs\My1CService`). *Чаще используется путь по умолчанию виртуального хоста Apache.*
3. **Закладка "Публикация":**
    * Убедитесь, что наш сервис `УчебныйСервис` отмечен **галочкой** в списке HTTP-сервисов.
4. **Закладка "Настройки web-сервера":**
    * Убедитесь, что порт веб-сервера указан верно (обычно `80` или `8080`).
5. **Нажмите "Опубликовать"**. Должно появиться сообщение об успешной публикации.
6. **Перезапустите службу Apache** (через `services.msc` или командой `net stop apache2.4` и `net start apache2.4`).

### **Часть 4: Проверка работы HTTP-сервиса**

#### **Шаг 4.1: Проверка базовой доступности веб-сервера**
1. Откройте браузер.
2. Перейдите по адресу: `http://localhost/My1CService`. Вы должны увидеть стандартную страницу 1С с надписью **"Веб-сервис опубликован"** или что-то подобное. Если страница не открывается — проверьте публикацию и работу Apache.

#### **Шаг 4.2: Проверка работы нашего сервиса**
1. В браузере перейдите по адресу, который собирается по правилу:
    `http://localhost/My1CService/УчебныйСервис/v1/catalog/`
    * `localhost` - адрес вашего веб-сервера.
    * `My1CService` - имя публикации.
    * `/УчебныйСервис/v1/catalog/` - Корневой URL + URL шаблона.
2. Если все настроено верно, вы должны получить **JSON-ответ** с массивом номенклатуры, ее ценами и штрихкодами.

**Пример ожидаемого ответа (в браузере или инструментах вроде Postman):**
```json
{
  "Номенклатура": [
    {
      "Наименование": "Ноутбук X200",
      "Артикул": "NTB-X200",
      "Цена": 75000.00,
      "Описание": "Игровой ноутбук",
      "ШтрихКоды": ["1234567890123", "9876543210987"]
    }
  ],
  "КоличествоЗаписей": 1,
  "ДатаФормирования": "2024-05-24T10:30:00"
}
```

### **Возможные проблемы и решения:**
* **Ошибка 404 (Не найдено):** Проверьте путь в браузере, наличие слешей, правильность имени публикации и корневого URL.
* **Ошибка 500 (Внутренняя ошибка сервера):** Откройте **журнал регистрации** 1С (в Конфигураторе: `Сервис -> Журнал регистрации`). Включите отладку и посмотрите детали ошибки. Частая причина — ошибка в коде функции или отсутствие прав.
* **"Служба не доступна":** Убедитесь, что сервер 1С:Предприятие запущен для этой базы в режиме сервера, или используйте **толстый клиент** для публикации файлового варианта базы.
* **Пустой ответ или ошибка кодировки:** Убедитесь, что в методе сервиса вы устанавливаете заголовок `Content-Type` и используете кодировку `UTF8`.
